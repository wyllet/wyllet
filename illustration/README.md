# Wyllet illustration kit

Prompts for generating Wyllet artwork, plus the logo files to attach as reference images.

| File | What it is |
| --- | --- |
| `logo.png` | The mascot on a solid background. Attach it as the **character reference** in every prompt. |
| `logo-transparent.png` | The same mascot with a transparent background. Use it for image-to-video and compositing. |
| `prompts-1.txt` | Mascot expressions, set 1: calm, cool, rude, surprised |
| `prompts-2.txt` | Mascot expressions, set 2: happy, sleepy, wink, worried |
| `prompts-3.txt` | Blog cover images (4) |
| `prompts-4.txt` | Landing page spot illustrations (4) |
| `higgsfield-video-1.txt` | Short hero video prompts for Higgsfield (image to video) |

## How to use

1. Attach `logo.png` as the reference image, every time. The character must stay identical; only what the prompt changes may change.
2. Paste one image block at a time (each file has at most 4). Generate 2 to 4 variations and keep the one that matches the reference best.
3. Save the results in `illustration/output/` with the exact filename given in each block. The site will pick them up from there.

## The character, in one paragraph

Wyllet is a small, rounded, box-shaped wallet with a hinged lid that sits slightly open. It is made of soft matte mint plastic (#48ECD2, slightly darker #2FCFB6 in the shadows) with gently rounded edges, like a premium vinyl toy. Its face is just two vertical black pill-shaped eyes on the front, set a little right of center, with a faint glossy highlight. There is no mouth, no nose, no arms and no legs unless a prompt says so. Expressions come from the eyes alone, and the lid can tilt to add attitude.

## Rules for every image

- Same proportions, colour and lid as the reference. No redesign.
- Soft studio lighting, one key light from the upper left, soft contact shadow.
- Clean backgrounds only: transparent, Ink `#06110F`, or Paper `#F1F8F6`, as each block says.
- No text, letters, logos, watermarks, coins, crypto symbols, glowing circuits, holograms, neon grids, lens flares, plastic shine, or cluttered props.
