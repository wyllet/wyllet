## Rules for a correct integration

These are the mistakes assistants make most often. Each rule is checked against the library source.

### Packages

- Install `wyllet` together with its peers: `wagmi`, `viem`, `@tanstack/react-query`, `react` and `react-dom`. Wyllet has no other runtime dependencies.
- Install `@walletconnect/ethereum-provider` only when `walletConnectProjectId` is set. It is an optional peer.
- Wyllet requires wagmi v3. Tutorials written for wagmi v2 use APIs that have since changed, so prefer these docs and the wagmi v3 reference.

### Providers and client components

- The package ships with a `'use client'` directive. Call `getDefaultConfig()`, theme presets such as `obsidianTheme()` and `withDefaultTokens()` from client modules only.
- Nest the providers in this order: `WagmiProvider`, then `QueryClientProvider`, then `WylletProvider`. Every Wyllet component and hook must render inside `WylletProvider`.
- In Next.js, create the `QueryClient` inside `useState` in the providers component, and set `appUrl` in `getDefaultConfig()` because there is no `window` on the server.
- Do not import a stylesheet. Styles are injected automatically. `injectStyles={false}` plus `import 'wyllet/styles.css'` is only for apps that load styles themselves.

### Configuration

- The order of `chains` is the priority order, and the first chain is the default. Use `customChain()` for chains that `viem/chains` doesn't include.
- `getDefaultConfig()` accepts any wagmi `createConfig()` option except `chains`, `transports` and `connectors`, which it builds. Pass your own RPC URLs through `transports` in production.
- With a hand-written `createConfig()`, pass `wallets`, `appInfo` and `walletConnectProjectId` to `WylletProvider`, include `walletConnect({ showQrModal: false })`, and add `burner()` to the connectors if you use `burnerWallet()`.
- `burnerWallet()` is for local development only. It keeps a private key in `localStorage`.

### Opening the panel

- `useWylletButton()` takes an element: `open(e.currentTarget)` or `openAccount(el, 'activity')`.
- `useWyllet()` takes an options object: `openConnect({ anchor: e.currentTarget })` or `openTab('networks', { anchor })`.
- The popover presentation needs an anchor element. Without one it falls back to a modal.
- The keyboard shortcut is off until you pass `shortcut="mod+k"`.

### Sign-In With Ethereum

- The auth adapter needs `getNonce`, `verify` and `signOut`, and optionally `getSession`. Verify the signature and the nonce on your server, never only in the browser.
- Switching accounts or disconnecting signs the user out automatically. Don't add your own listener for that.

### Styling

- Change colors and radii through theme options or `overrides`, not by targeting internal class names.
- To override `--wy-*` variables from your own stylesheet, use a selector at least as specific as `:root [data-wyllet]`.

## A complete reference implementation

This is the smallest correct Next.js App Router setup. It is a good target to compare generated code against.

```ts title="lib/wagmi.ts"
import { base, mainnet } from 'viem/chains'
import { getDefaultConfig } from 'wyllet'

export const config = getDefaultConfig({
  appName: 'My dApp',
  appUrl: 'https://my-dapp.xyz',
  walletConnectProjectId: process.env.NEXT_PUBLIC_WC_PROJECT_ID,
  chains: [mainnet, base],
  ssr: true,
})
```

```tsx title="app/providers.tsx"
'use client'

import { QueryClient, QueryClientProvider } from '@tanstack/react-query'
import { useState, type ReactNode } from 'react'
import { WagmiProvider } from 'wagmi'
import { obsidianTheme, WylletProvider } from 'wyllet'
import { config } from '@/lib/wagmi'

export function Providers({ children }: { children: ReactNode }) {
  const [queryClient] = useState(() => new QueryClient())
  return (
    <WagmiProvider config={config}>
      <QueryClientProvider client={queryClient}>
        <WylletProvider theme={obsidianTheme({ accentColor: '#48ECD2' })} shortcut="mod+k">
          {children}
        </WylletProvider>
      </QueryClientProvider>
    </WagmiProvider>
  )
}
```

```tsx title="app/layout.tsx"
import type { ReactNode } from 'react'
import { WylletButton } from 'wyllet'
import { Providers } from './providers'

export default function RootLayout({ children }: { children: ReactNode }) {
  return (
    <html lang="en">
      <body>
        <Providers>
          <header>
            <WylletButton />
          </header>
          {children}
        </Providers>
      </body>
    </html>
  )
}
```

## Check the result

Before you accept generated code, check that:

1. `wyllet` appears in `package.json` with `wagmi` v3 and `viem` v2, and no other wallet connector library was added.
2. The providers file starts with `'use client'` and nests the three providers in the right order.
3. There is no Wyllet CSS import.
4. The button opens the panel, installed wallets appear under **Detected**, and the WalletConnect option shows a QR code once a project ID is set.
5. Every prop and hook used appears in the [Provider](/docs/provider), [Hooks](/docs/hooks) or [Components](/docs/components) reference.
